# 실기기(iPhone) 점검표

> **2026-11-19 · iPhone(홈 화면 앱) · 22/22 통과.** 배포 `1b92e00` 기준. 실기기에서 함께 확인: 중량 입력 직후 '세트 완료' 한 번 탭, 운동 시작 직후 첫 세트가 스크롤 없이 보임, 보유 덤벨 목록, 세트 간 무게 유지.

자동 테스트는 헤드리스 Chromium(iPhone 뷰포트)에서만 돌았습니다. 아래는 **실제 iPhone에서 직접 확인해야 하는 항목**입니다.
실패하면 항목 번호와 증상을 알려주세요.

## 설치 · 오프라인
1. [x] Safari로 배포 주소 열기 → 공유 → **홈 화면에 추가** → 아이콘/이름(Push&Pull)이 맞다.
2. [x] 홈 화면 아이콘으로 실행 시 주소창 없이 전체 화면, 상태바가 어둡다.
3. [x] 한 번 실행한 뒤 **비행기 모드** → 앱 종료 후 재실행 → 루틴/기록이 보인다.
4. [x] 비행기 모드에서 운동 시작 → 세트 완료 → 종료까지 가능하다.
5. [x] 설정 맨 아래 "저장소" 문구가 표시된다(영구 보존 허용 여부).

## 타이머 (가장 중요)
6. [x] 세트 완료 → 타이머 자동 시작, 숫자가 1초씩 줄어든다.
7. [x] 타이머 중 **홈 버튼으로 앱 전환 → 20초 후 복귀** → 남은 시간이 실제 경과만큼 줄어 있다.
8. [x] 타이머 중 **화면 잠금 → 30초 후 해제** → 남은 시간이 정확하다.
9. [x] 타이머가 끝난 뒤 복귀하면 `휴식 끝 +mm:ss`가 보이고 소리가 **울리지 않는다**(예상 동작).
10. [x] 화면을 켠 채 타이머가 끝나면 알림음이 난다(무음 스위치 OFF, 볼륨 확인). 진동은 iPhone에서 없는 것이 정상.
11. [x] 운동 중 화면이 자동으로 꺼지지 않는다(Wake Lock). 꺼진다면 어느 iOS 버전인지 알려주세요.
12. [x] 타이머 하단 "잠금 중에는 알림이 울리지 않아요" 안내가 보이고 눌러서 설명이 열린다.

## 한 손 조작
13. [x] 엄지만으로 −/+ 버튼, RIR, **세트 완료** 버튼에 닿는다(화면 하단 타이머 바에 가려지지 않는다).
14. [x] 중량 숫자를 직접 탭해 입력할 때 키패드가 소수점을 지원하고, 화면이 확대되지 않는다.
15. [x] 세트 완료 후 다음 세트 패널이 자동으로 화면에 보인다.
16. [x] 슈퍼세트(운동 순서 ↔ 버튼): 첫 운동 세트 완료 → 바로 짝 운동으로 이동, 둘째 운동 뒤에만 타이머.

## 복구 · 데이터
17. [x] 운동 중 앱을 **강제 종료** 후 재실행 → "진행 중인 운동 이어하기"로 세트가 그대로다.
18. [x] JSON 백업 내보내기 → 파일 앱에 저장/공유 시트가 열린다(저장 위치 확인).
19. [x] 다른 브라우저/기기에서 그 JSON으로 복원 → 기록이 같다.
20. [x] CSV를 Numbers/Excel에서 열었을 때 한글이 깨지지 않는다.

## 레이아웃
21. [x] 노치/다이나믹 아일랜드, 하단 홈 인디케이터와 내비·타이머 바가 겹치지 않는다.
22. [x] 가로 스크롤이 생기지 않는다. 시트(모달)가 화면 밖으로 잘리지 않는다.
